# เว็บไซต์ Resume — เมธา ทองบุญนาก

เปิด index.html เพื่อดูเว็บในเครื่อง เว็บไซต์ใช้ HTML และ CSS ไม่มี framework

## ข้อมูลที่ยังขาด
- ยืนยันอีเมล
- ข้อดี 3 ข้อ และสิ่งที่อยากพัฒนา 2–3 ข้อ
- เกรดเฉลี่ยระดับมัธยมศึกษา
- รายละเอียดฝึกงาน/ทำงาน/อบรม: หน่วยงาน ช่วงเวลา และหน้าที่
- ผลงานชิ้นที่ 3 พร้อมคำอธิบายและเทคโนโลยี
- รูปผลงานหรือลิงก์ repository ของแต่ละโครงงาน
- LinkedIn หรือโซเชียลอื่น (ถ้ามี)

ข้อมูลในเว็บอ้างอิงภาพ Resume ข้อมูลที่เจ้าของประวัติส่งมา และใบผลการศึกษาวันที่ 24 ธันวาคม 2568 ไม่มีการแต่งข้อมูลส่วนที่ขาด เกรดเฉลี่ย 2.34 เป็นค่าตามเอกสารฉบับนั้น
รูปโปรไฟล์ที่ส่งมามีขนาดต้นฉบับ 160×160 จึงอาจไม่คมเมื่อขยาย หากมีรูปใหญ่กว่าให้แทน images/profile.jpg

## นำขึ้น GitHub Pages ตามคู่มือ
1. สร้าง repository เช่น my-resume ในบัญชี tongboonnakem-alt
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ โดยให้ index.html อยู่ที่ชั้นแรกของ repository
3. ที่ Settings > Pages เลือก Deploy from a branch และเลือก main / (root)
4. เมื่อติดตั้งเสร็จ เว็บจะอยู่ที่ https://tongboonnakem-alt.github.io/my-resume/

ก่อนเผยแพร่ ให้เติมข้อมูลที่ขาดและลบกล่องข้อความรอข้อมูลในหน้าเว็บ
